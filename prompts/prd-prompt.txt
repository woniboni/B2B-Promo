# 비즈니스 관련 정보
 - 목표 사용자: 2000개 이상의 거래처가 등록하여 사용
 - 비즈니스 목표: 1000개 이상의 거래처가 프로모션 기능을 이용함

# 기술 제약사항
 - 플랫폼 우선순위: 웹 어플리케이션 개발, 모바일은 반응형 UI로만 고려함.
   * 반응형 웹UI를 반드시 적용
 - 인프라 제약
   * 프론트엔드: React19, 전역상태관리(Zustand), TanstackQuery를 이용해 백엔드와 통신
   * 백엔드: node.js+express, pg 라이브러리
   * 데이터베이스: postgresql 17

# 프로젝트 관리
