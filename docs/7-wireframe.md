## 범례
- `[ 버튼 ]` : 클릭/탭 가능한 액션 버튼
- `(비활성)` : 조건에 따라 비활성화되는 버튼/상태
- 각 화면 하단에 **표시 데이터**(도메인 정의서 2-1절 엔티티 필드 기준), **사용자 액션**, **관련 UC/BR/EX**를 표로 정리한다.

### 1.4 PromotionDetailPage (UC-2, UC-3, UC-4) — Must, 상세 작성

**(A) 일반 프로모션 (쿠폰 이벤트 없음)**

```
+-------------------------------+
| <  뒤로                       |
+-------------------------------+
|  [가격할인]                    |
|  여름 성수기 특가               |
+-------------------------------+
|  설명(description)             |
|  ------------------------     |
|  ------------------------     |
|  ------------------------     |
+-------------------------------+
|  [     참여 신청하기     ]      |  -> 액션: 참여 신청 (UC-3)
+-------------------------------+
```

**(B) 쿠폰 이벤트 프로모션 — 모집 중**

```
+-------------------------------+
| <  뒤로                       |
+-------------------------------+
|  [1+1] [쿠폰이벤트]            |
|  신제품 런칭 1+1                |
+-------------------------------+
|  설명(description)             |
|  ------------------------     |
+-------------------------------+
|  쿠폰 이벤트 (선착순 50명)       |
|  잔여 27 / 50명 남음            |  <- CouponEvent.capacity(50), applied_count 기반(BR-6)
|  [====진행바(23/50)========]  |
+-------------------------------+
|  [     참여 신청하기     ]      |  -> 액션: 참여 신청 (UC-3 -> UC-4)
+-------------------------------+
```

**(C) 쿠폰 이벤트 프로모션 — 마감(50명 도달)**

```
+-------------------------------+
|  쿠폰 이벤트 (선착순 50명)       |
|  마감되었습니다 (0 / 50명 남음)   |  <- applied_count >= capacity (BR-6, EX-1)
+-------------------------------+
|  [   마감되었습니다   ] (비활성)  |  -> 버튼 비활성화, 신청 불가
+-------------------------------+
```

**(D) 참여 신청 시 즉시 추첨 결과 모달 (쿠폰 이벤트에 한함)**

```
        +-----------------------+
        |     축하합니다! 🎉      |
        |                       |
        |   당첨 할인율: 10%     |  <- DrawResult.discount_rate (BR-4)
        |                       |
        |  유효기한: 2026-09-13  |  <- DrawResult.expires_at
        |  (확정일로부터 1개월)    |     = confirmed_at + 1개월 (BR-8)
        |                       |
        |  ※ 재추첨은 제공되지    |
        |    않습니다(BR-5)      |
        |                       |
        |    [   확인   ]        |  -> 액션: 모달 닫고 내 신청 목록으로
        +-----------------------+
```

**(E) 일반 프로모션 신청 완료 안내(모달 없이 인라인)**

```
+-------------------------------+
|  "신청이 완료되었습니다"        |
|  [   내 신청 목록 보기   ]      |
+-------------------------------+
```

**(F) 종료된 프로모션에 직접 링크로 진입한 경우(EX-3)**

```
+-------------------------------+
|  이 프로모션은 종료되었습니다     |
|  신규 참여 신청은 불가합니다      |  <- BR-11, EX-3
|  [   참여 신청하기   ] (비활성)  |
+-------------------------------+
```

| 구분 | 내용 |
|---|---|
| 표시 데이터 | Promotion(title, type, description), CouponEvent(capacity=50, applied_count → 잔여 = capacity - applied_count), 신청 성공 시 DrawResult(discount_rate, expires_at) |
| 사용자 액션 | 참여 신청하기(활성/비활성), 추첨 결과 모달 확인, 내 신청 목록으로 이동 |
| 관련 UC/BR/EX | UC-2, UC-3, UC-4, BR-3, BR-4, BR-5, BR-6, BR-7, BR-8, BR-9, BR-10, BR-11, EX-1, EX-2, EX-3 |
| 비고 | 잔여 정원 표시와 마감 시 버튼 비활성화(BR-6, BR-7, EX-1)는 반드시 이 화면에서 구현. 이미 신청됨 상태(중복 신청 시도)면 "이미 신청한 프로모션입니다" 안내(EX-2)로 버튼 대신 메시지를 노출한다. |

### 1.5 MyApplicationsPage (UC-5) — Must, 상세 작성

```
+-------------------------------+
| <  뒤로       내 신청 목록       |
+-------------------------------+
| +---------------------------+ |
| | [1+1] 신제품 런칭 1+1        | |
| | 상태: 신청됨                 | |  <- Application.status = 신청됨(BR-3)
| | 당첨 10% (~2026-09-13)      | |  <- DrawResult (BR-8)
| | [   취소하기   ]             | |  -> 액션: 신청 취소
| +---------------------------+ |
| +---------------------------+ |
| | [가격할인] 여름 성수기 특가    | |
| | 상태: 취소됨                 | |  <- Application.status = 취소됨
| | [   재신청하기   ]           | |  -> 액션: 재신청(BR-3, EX-2)
| +---------------------------+ |
| +---------------------------+ |
| | [샘플증정] 봄맞이 샘플 이벤트  | |
| | 상태: 신청됨 | [종료된 프로모션]| |  <- Promotion.status=종료됨이어도
| | [   취소하기   ]             | |     계속 노출(BR-10), 취소 가능(BR-11)
| +---------------------------+ |
+-------------------------------+
```

| 구분 | 내용 |
|---|---|
| 표시 데이터 | Application(status: 신청됨/취소됨), 소속 Promotion(title, type, status), 있으면 DrawResult(discount_rate, expires_at) |
| 사용자 액션 | 신청됨 건: 취소하기 / 취소됨 건: 재신청하기(단, 해당 Promotion이 종료됨이면 재신청 버튼 미노출 — EX-3, BR-11. 쿠폰 이벤트 건은 재신청 시점에 정원 마감 여부를 재확인하며, 마감됐다면 버튼을 눌러도 거부되고 "마감되었습니다" 안내가 뜬다 — BR-5, BR-6, EX-4) |
| 관련 UC/BR/EX | UC-5, BR-3(상태 전환 방식), BR-5(재신청 시 재추첨·upsert), BR-6(마감 시 재신청도 거부), BR-8(당첨 유효기한 표시), BR-10(종료 프로모션도 계속 조회), BR-11(종료 후 취소는 허용), EX-2, EX-3, EX-4 |
| 비고 | 종료된 프로모션 건에는 "[종료된 프로모션]" 태그를 추가로 표시해 프로모션 목록(PromotionListPage)에서는 빠졌지만 신청 이력에는 남아있음을 구분한다(BR-9~11). |

## 3. 반응형 요약 (PRD 6.1절)

- 거래처 담당자 화면(1절)은 모바일 좁은 세로 레이아웃(카드 1열, 하단 액션 버튼 풀폭)을 기준으로 설계하고, 데스크탑에서는 카드 그리드/여백 확장으로 반응형 대응한다(1.3절 예시 참고).
- 관리자 화면(2절)은 데스크탑 표 형태 레이아웃을 기준으로 설계하고, 모바일에서는 표 대신 카드형 리스트로 축소되는 것을 전제로 하되 별도 관리자 전용 레이아웃 프레임워크 없이 동일 코드베이스의 CSS 미디어 쿼리로 처리한다(PRD 6.1절 동기화).
- 접근성(a11y)은 본 프로젝트 범위 밖이므로 본 와이어프레임에서 포커스 순서, 스크린리더 라벨 등은 다루지 않는다.
